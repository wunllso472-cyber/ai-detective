# 查证 · AI侦探社

本 Skill 是「查证 · AI侦探社」Web 服务的命令行客户端，所有搜索、核对、溯源都在服务端完成（元宝搜索 + 火山引擎方舟模型）。脚本零依赖，只需要 Node.js 18+。

## 前置条件

- 服务地址由环境变量 `DETECTIVE_API` 指定，默认 `http://localhost:3000`。
- 先确认服务可用：`node scripts/detective.mjs status`。连不上时告诉用户先启动服务（项目目录下 `npm run dev` 或 `npm start`），或提供已部署的地址；**不要**自己凭知识回答查证问题来代替。
- `status` 里如果显示“模拟”，说明服务端没配置密钥，结果是演示数据，必须向用户说明。

## 用法

脚本路径相对本 SKILL.md 所在目录：

| 任务 | 命令 | 耗时 |
|---|---|---|
| 基础查证 | `node scripts/detective.mjs verify "要查证的问题或消息"` | 约 20–60 秒 |
| 深度调查（生成报告） | `node scripts/detective.mjs deep "调查对象" --rounds 3` | 约 1–3 分钟 |
| 截图查证 | `node scripts/detective.mjs screenshot 图片路径 [--note "补充说明"]` | 约 30–90 秒 |
| 持续盯梢 | `node scripts/detective.mjs watch <结果ID> [--interval 60]` | 立即返回 |
| 立即检查盯梢 | `node scripts/detective.mjs check <盯梢ID> [--freshness d7]` | 约 20–60 秒 |
| 查看提醒 | `node scripts/detective.mjs notifications` | 立即返回 |

- 加 `--json` 输出完整 JSON（结构化字段：verdict、claims、sources、trace 等）。
- 命令耗时较长，执行时把超时设到 5 分钟以上（深度调查 10 分钟）。

## 如何向用户呈现结果

1. 先给结论标签（有据可查 / 存疑 / 与证据不符 / 证据不足）和一两句话结论。
2. 列出关键依据：引用原文 + 来源网站 + 日期 + 链接。只用脚本输出里的来源，**不要补充脚本没给出的来源或事实**。
3. 有溯源信息时说明最早可查来源和是否存在大量同源转载。
4. 给出详情页链接（输出里的“详情页”），深度调查再给出“调查报告”链接。
5. “证据不足”时如实说明，不要用自己的知识下结论。
6. 用户想跟踪后续时，用 `watch` 加上结果 ID（输出末尾“详情页”链接里 `/r/` 后面的部分）。

## 判定含义

- **有据可查**：多个独立来源（或权威来源）支持，几乎没有反驳。
- **与证据不符**：多个独立来源（或权威来源）反驳 / 辟谣。
- **存疑**：支持与反驳并存，或证据互相矛盾。
- **证据不足**：有效独立来源太少，无法判断。

所有引用都经过“原文逐字校验”：模型声称的引用如果在来源文本里找不到，会被拦截且不计入证据。
